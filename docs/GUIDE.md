## 1. Что понадобится

**Сервер (VPS)**

- Чистый образ Debian 12 или Ubuntu 24.04 LTS (подойдут и Debian 11/13, Ubuntu 20.04/22.04/26.04).
- Сервер должен находиться в стране из [списка Anthropic](https://www.anthropic.com/supported-countries),
  например в Нидерландах, Германии или Финляндии. Иначе Claude Code не сможет работать
  с сервера, и скрипт предупредит об этом.
- Память: от 2 ГБ, лучше 4 ГБ. Если памяти меньше 4 ГБ, скрипт сам добавит swap на 2 ГБ.
- Диск: свободно хотя бы 3 ГБ, плюс место под ваши проекты.
- Из панели хостинга: IP-адрес, SSH-порт (обычно 22) и пароль root.
- Лучше без предустановленных панелей управления и чужих сервисов.

**Ваш компьютер**

- Windows 10/11: Windows PowerShell и компонент «Клиент OpenSSH» (в Windows 10 1809+ и
  Windows 11 обычно уже есть; проверка: `ssh -V`).
- macOS или Linux: Терминал, `ssh` и `curl` (обычно уже есть).
- Любой из браузеров: Chrome, Edge, Brave, Яндекс Браузер, Vivaldi или Firefox.
  На Windows Edge есть всегда.
- VS Code, если хотите работать в редакторе: https://code.visualstudio.com/
- Подписка Claude Pro или Max (или аккаунт Claude Console).

## 2. Запуск установщика

Команды выполняются **на вашем компьютере**. Заходить на сервер заранее не нужно.

**Windows.** Пуск → наберите `PowerShell` → откройте «Windows PowerShell». Вставьте
(правая кнопка мыши) и нажмите Enter:

```powershell
irm https://raw.githubusercontent.com/Djam36/claude-code-vps/main/install.ps1 | iex
```

Команда рассчитана на PowerShell, а не на старое окно `cmd`.

**macOS.** Откройте приложение «Терминал» (Cmd+Пробел → «Терминал») и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/Djam36/claude-code-vps/main/install.sh | bash
```

**Linux.** То же самое в любом терминале. `sudo` перед командой писать не нужно.

Если не хотите запускать скрипт прямо из интернета, скачайте репозиторий и запустите
локальный файл: `bash install.sh` на macOS/Linux или `pwsh -File .\install.ps1` в
PowerShell 7 на Windows. Тогда `bootstrap.sh` тоже берётся из этой папки. Старый
Windows PowerShell 5.1 читает файл без BOM в неверной кодировке, поэтому в нём
используйте команду с `irm` из начала раздела.

## 3. Что вы увидите во время установки

1. **IP-адрес или домен сервера** — вставьте адрес из панели хостинга, без `http://`.
2. **SSH-порт [22]** — если хостинг не указал другой, просто нажмите Enter.
3. **Отпечаток сервера.** При первом подключении SSH может спросить
   `Are you sure you want to continue connecting (yes/no)?` — напишите `yes`.
4. **Пароль root** — вставьте пароль и нажмите Enter. Символы при вводе не видны,
   даже звёздочки. Это нормально. Пароль нужен один раз: дальше скрипт работает по ключу.
5. Дальше скрипт работает сам и пишет, что делает:
   - `Шаг 3/5` — обновляет пакеты, ставит Claude Code, создаёт пользователя `dev`;
   - `Шаг 4/5` — проверяет, что вход под `dev` по ключу работает, и сохраняет у вас
     пароль для `sudo`;
   - `Шаг 5/5` — включает защиту: вход только по ключу, без root, брандмауэр, fail2ban,
     автообновления.
6. В конце появится `Готово! Сервер настроен.` и вопрос, войти ли в Claude Code сейчас.

Не закрывайте окно, пока идёт установка. Если что-то пошло не так, скрипт остановится
и напишет причину; root и вход по паролю отключаются только после успешной проверки входа
под `dev`, поэтому доступ к серверу вы не потеряете.

## 4. Вход в Claude Code

Если на вопрос «Войти в Claude Code сейчас?» вы ответили Enter, или позже выполнили
`claude-vps login`, происходит следующее:

1. Поднимается SSH-туннель, и скрипт пишет, с какого IP браузер будет выходить в
   интернет. Это должен быть IP вашего сервера.
2. Открывается **отдельное окно браузера** со страницей claude.ai. Войдите в свой
   аккаунт Claude. Это окно ходит в интернет через сервер, поэтому claude.ai его пускает.
   Ваш обычный браузер не затрагивается.
3. Вернитесь в терминал и нажмите Enter. На сервере запустится Claude Code.
4. Выберите тему оформления, затем способ входа **Claude account with subscription**.
5. Claude Code покажет длинную ссылку. Нажмите `c`, чтобы скопировать её, или выделите
   мышью. Откройте ссылку **в том же отдельном окне** браузера из пункта 2.
6. Нажмите **Authorize**. На странице появится код. Скопируйте его, вставьте в терминал
   в строку `Paste code here if prompted` и нажмите Enter.
7. Появится `Login successful`. Нажмите Enter.
8. Проверьте вход командой `/status` — там будет ваш аккаунт. Выйти из Claude Code:
   `/exit`. Туннель закроется сам.

Окно браузера через сервер можно открыть и отдельно: `claude-vps browser`. Пока окно
терминала с этой командой открыто, браузер ходит через сервер.

## 5. Подключение VS Code

1. В VS Code откройте Extensions (Ctrl+Shift+X) и установите **Remote - SSH** от Microsoft.
2. Откройте палитру команд: Ctrl+Shift+P (на Mac Cmd+Shift+P) →
   `Remote-SSH: Connect to Host...` → выберите **claude-vps**.
3. Если VS Code спросит платформу сервера — выберите **Linux**. Первое подключение
   занимает минуту: VS Code ставит на сервер свою серверную часть.
4. Внизу слева должно появиться `SSH: claude-vps`.
5. Терминал (Terminal → New Terminal) уже открыт на сервере. Проверка:

   ```bash
   whoami          # dev
   claude --version
   ```

Добавлять хост вручную и вводить IP не нужно: подключение `claude-vps` уже записано
в `~/.ssh/config`.

**Расширение Claude Code для VS Code.** В окне `SSH: claude-vps` установите расширение
Claude Code от Anthropic (кнопка «Install in SSH: claude-vps»). Обычно оно использует
тот же вход, что и Claude Code в терминале. Если оно всё же попросит войти: запустите на
своём компьютере `claude-vps browser`, скопируйте ссылку входа из VS Code и откройте её
в открывшемся окне браузера.

## 6. Работа с проектом

```bash
mkdir -p ~/work/my-project
cd ~/work/my-project
claude
```

В VS Code откройте папку через File → Open Folder → `/home/dev/work/my-project`.

Полезные команды Claude Code:

- `claude --continue` — продолжить последний разговор в этой папке;
- `claude --resume` — выбрать один из прошлых разговоров;
- `/status` — какой аккаунт и модель используются.

Node.js, Python и другие инструменты для проекта на сервер не ставятся заранее. Попросите
Claude поставить то, что нужно проекту. Для `sudo` нужен пароль из файла
`~/.claude-vps/sudo-password-claude-vps.txt` на вашем компьютере: если Claude попросит
выполнить команду с `sudo`, выполните её сами в терминале.

## 7. Как открыть сайт, запущенный на сервере

Допустим, Claude запустил проект командой `npm run dev`, и тот слушает порт 3000 на сервере.

**Вариант 1 — VS Code.** Обычно VS Code сам замечает порт и предлагает открыть его.
Если нет: нижняя панель → вкладка **Ports** → **Forward a Port** → `3000`. Откройте
адрес, который покажет VS Code.

**Вариант 2 — команда:**

```bash
claude-vps open 3000
```

Откроется `http://127.0.0.1:3000` в вашем обычном браузере. Если порт 3000 у вас занят,
скрипт возьмёт следующий свободный и напишет адрес. Enter закрывает проброс.

Открывать порт сайта в брандмауэре не нужно: трафик идёт внутри SSH.

## 8. tmux: чтобы Claude не останавливался при обрыве связи

Если связь пропадёт, обычный процесс в терминале остановится. tmux держит сессию на
сервере, пока сервер не перезагрузится.

```bash
claude-vps attach      # на компьютере: войти в постоянную сессию (или создать её)
claude                 # внутри tmux
```

Отсоединиться, не останавливая Claude: **Ctrl+B**, затем **D**. Вернуться: снова
`claude-vps attach`. Внутри сервера то же самое: `tmux new -A -s claude`. Список сессий:
`tmux ls`. Прокрутка мышью включена.

## Как сделать то же самое руками

Скрипт не делает ничего секретного. Вот ручные эквиваленты главных команд.

**Браузер через сервер (то, что делают `login` и `browser`):**

```bash
# 1. SOCKS5-прокси на вашем компьютере. Окно оставьте открытым.
ssh -N -D 127.0.0.1:1080 claude-vps

# 2. Браузер в отдельном профиле через этот прокси (пример для Chrome на macOS):
open -na "Google Chrome" --args --user-data-dir="$HOME/.claude-vps/browser/manual" \
  --proxy-server="socks5://127.0.0.1:1080" https://claude.ai/login
```

Windows (PowerShell), Edge:

```powershell
ssh -N -D 127.0.0.1:1080 claude-vps   # в отдельном окне
& "${env:ProgramFiles(x86)}\Microsoft\Edge\Application\msedge.exe" `
  --user-data-dir="$env:USERPROFILE\.claude-vps\browser\manual" `
  --proxy-server="socks5://127.0.0.1:1080" https://claude.ai/login
```

В Firefox то же настраивается в Настройках → Параметры сети → Ручная настройка прокси:
узел SOCKS `127.0.0.1`, порт `1080`, SOCKS v5, галочка «Отправлять DNS-запросы через
прокси при использовании SOCKS v5».

**Сайт с сервера (то, что делает `open 3000`):**

```bash
ssh -N -L 127.0.0.1:3000:127.0.0.1:3000 claude-vps
# затем откройте http://127.0.0.1:3000
```

Разница между ними:

- `-L` (локальный проброс) — один конкретный порт сервера становится портом у вас.
  Подходит, чтобы посмотреть свой сайт.
- `-D` (динамический проброс) — у вас появляется прокси, через который можно ходить на
  любые сайты, и они видят IP сервера. Подходит для входа в claude.ai.

**Что настроено на сервере** — всё в отдельных файлах, их легко найти и удалить:

| Файл | Зачем |
|---|---|
| `/etc/ssh/sshd_config.d/00-claude-vps.conf` | вход только по ключу, без root |
| `/etc/fail2ban/jail.d/claude-vps.conf` | защита SSH от перебора |
| `/etc/apt/sources.list.d/claude-code.list`, `/etc/apt/keyrings/claude-code.asc` | репозиторий Claude Code |
| `/etc/apt/apt.conf.d/52claude-vps` | автообновления системы и Claude Code (перекрывает `20auto-upgrades`) |
| `/etc/sudoers.d/90-claude-vps-install` | временный sudo без пароля на время установки; убирается на шаге 5, при ошибке, через час (таймер `claude-vps-sudo-cleanup`) или при перезагрузке сервера |
| `/swapfile-claude-vps` | swap на маленьких серверах |
| `/var/log/claude-vps-install.log` | журнал установки |

UFW открывает все порты, на которых слушает SSH: из `sshd_config`, из `ssh.socket` (Ubuntu
22.10+) и порт, через который установщик подключён прямо сейчас. Так нестандартный порт
хостинга не закроется.

## Если что-то не работает

**`Не найден ssh.exe` / `ssh: command not found`.** Windows: Параметры → Приложения →
Дополнительные компоненты → Добавить компонент → «Клиент OpenSSH». Откройте PowerShell
заново. macOS/Linux: установите OpenSSH Client (`sudo apt install openssh-client`).

**PowerShell пишет, что выполнение сценариев отключено.** Команда `irm … | iex` не
требует менять политику. Если запускаете файл, используйте
`pwsh -ExecutionPolicy Bypass -File .\install.ps1` (PowerShell 7).

**`Permission denied` при вводе пароля root.** Проверьте пароль в панели хостинга. Часть
хостингов выдаёт не root, а пользователя вроде `ubuntu` с ключом — тогда запустите с
`CCV_ADMIN_USER=ubuntu`.

**`apt` занят, установка долго ждёт.** Сразу после создания VPS хостинг ставит
обновления. Скрипт ждёт до 10 минут. Не удаляйте lock-файлы apt.

**`api.anthropic.com ответил 403`.** Сервер находится в стране, которую Anthropic не
обслуживает. Нужен VPS в другой стране.

**Браузер открылся, но claude.ai пишет, что недоступен в вашем регионе.** Проверьте IP,
который вывел скрипт: это должен быть IP сервера. Если окно браузера было открыто раньше
с другим портом, закройте все окна этого профиля и запустите `claude-vps login` снова.

**Не открывается автоматически браузер.** Скрипт напишет порт прокси. Настройте прокси
вручную, как в разделе выше.

**`REMOTE HOST IDENTIFICATION HAS CHANGED`.** Сервер переустановили или IP достался
другому серверу. Убедитесь в этом в панели хостинга, затем удалите старую запись:
`ssh-keygen -R АДРЕС` (для нестандартного порта: `ssh-keygen -R "[АДРЕС]:ПОРТ"`) и
запустите установку снова.

**Сервер спрашивает пароль sudo при повторной установке.** Он в файле
`~/.claude-vps/sudo-password-claude-vps.txt` на вашем компьютере.

**Пароль sudo потерян.** Войдите через консоль в панели хостинга под root и выполните
`passwd dev`.

**`claude-vps: command not found`.** Откройте новое окно терминала. На macOS/Linux
команда лежит в `~/.local/bin`, на Windows — в `%USERPROFILE%\.claude-vps\bin`.

**fail2ban не запустился.** Это не мешает работе. Подробности на сервере:
`sudo journalctl -u fail2ban -n 50`.

**Проверить защиту на сервере:**

```bash
sudo ufw status verbose          # Status: active, разрешён только SSH
sudo fail2ban-client status sshd # jail sshd существует
sudo sshd -T | grep -E 'permitrootlogin|passwordauthentication'
```

**Что прислать, если просите помощи:** ОС компьютера, версию Debian/Ubuntu, на каком
шаге остановилось и текст ошибки. Журнал сервера: `sudo tail -n 80 /var/log/claude-vps-install.log`.
Никогда не отправляйте пароли, приватный ключ и файл `~/.claude/.credentials.json`.

## Удаление

**На компьютере:**

- удалите блок между строками `# >>> claude-code-vps: claude-vps >>>` и
  `# <<< claude-code-vps: claude-vps <<<` в `~/.ssh/config`;
- удалите папку `~/.claude-vps` (Windows: `%USERPROFILE%\.claude-vps`) и ключи
  `~/.ssh/claude_vps_ed25519` и `~/.ssh/claude_vps_ed25519.pub`;
- macOS/Linux: удалите `~/.local/bin/claude-vps` и строку с пометкой
  `# claude-code-vps PATH` в `~/.zshrc` или `~/.bashrc`;
- Windows: уберите `%USERPROFILE%\.claude-vps\bin` из переменной Path пользователя
  и переменную `CLAUDE_VPS_HOME`.

**На сервере** проще всего переустановить систему в панели хостинга. Если нужно оставить
сервер: удалите файлы из таблицы выше, выполните `sudo systemctl reload ssh` и
`sudo apt remove claude-code`.
